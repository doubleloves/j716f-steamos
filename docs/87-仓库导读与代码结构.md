# 87 · 仓库导读与代码结构

本仓库来自一台 **Lenovo TB-J716F** 的长期改造，内容分三层：

1. **知识**：`docs/` —— 从迁移、驱动、问题排查到刷机/发布的全过程记录；
2. **脚本/配置**：`scripts/`、`configs/` —— 实机正在运行的定制脚本与 systemd/udev/UCM 配置；
3. **工具链**：`recovery/`、`release/`、`tools/`、`kernel/` —— 镜像构建、卡刷、线刷、内核补丁。

## 数据流（从源码到设备）

```
kernel/patches + config ─┐
                         ├─> build.sh ─> Image + DTB ─┐
initramfs（recovery/init）┘                          ├─> Android boot.img ──> boot_a/boot_b
                                                     │
release/build-rootfs.sh ─> rootfs.img.gz / rootfs.simg ─┴─> userdata(sda18)

卡刷：SD /j716f/*  ─> mini-recovery（recovery_a/b）─> 同上
线刷：install.ps1   ─> fastboot flash ───────────────> 同上
```

## 脚本与配置的部署

`scripts/` 与 `configs/` 不是自动安装器；迁移到新设备/新系统时按以下方式放：

```bash
# 脚本
sudo install -m755 scripts/j716f-* /usr/local/bin/
sudo install -m755 scripts/steam-arm-* scripts/steamos-* /usr/local/bin/

# systemd（按需 enable）
sudo cp configs/systemd/system/j716f-*.service configs/systemd/system/j716f-*.timer /etc/systemd/system/
sudo mkdir -p /etc/systemd/system/getty@tty1.service.d
sudo cp configs/systemd/system/getty@tty1.service.d/*.conf /etc/systemd/system/getty@tty1.service.d/
sudo systemctl daemon-reload

# udev / UCM / etc
sudo cp configs/udev/rules.d/*.rules /etc/udev/rules.d/
sudo mkdir -p /usr/share/alsa/ucm2/conf.d/sm8250 /usr/share/alsa/ucm2/Qualcomm/sm8250
sudo cp configs/ucm/conf.d/sm8250/*.conf /usr/share/alsa/ucm2/conf.d/sm8250/
sudo cp configs/ucm/Qualcomm/sm8250/*.conf /usr/share/alsa/ucm2/Qualcomm/sm8250/
sudo mkdir -p /etc/j716f && sudo cp configs/j716f/* /etc/j716f/

# greetd（按需）
sudo cp configs/greetd/config.toml /etc/greetd/config.toml
```

> 注意：这些脚本里引用的路径已统一为 `/home/j716f`（发布版策略）；如果用户名/家目录不同，请先按
> [docs/86](86-用户名通用化与首启自定义.md) 调整。
