## 0. 结论（先看这段）

发布版 = **从当前系统复制出一份干净 rootfs 镜像**（清理个人数据 + 首启脚本），再配：

1. `boot.img`（当前 `boot_a` 裁剪到有效长度）；
2. `rootfs.img.gz`（卡刷，mini-recovery 用 `/j716f/` payload）；
3. `rootfs.simg`（线刷，`fastboot flash userdata` 用，Android sparse）；
4. Windows `install.ps1` + `tools/platform-tools/fastboot.exe`；
5. `SHA256SUMS` / `manifest.txt` / README / NOTICE。

整套流程已脚本化在设备上运行（`release/build-rootfs.sh`），**不修改当前系统**，所有产物写到 SD 卡。
决策：**发布版**（清个人数据；不包含 Steam 账号/登录态/游戏库；Steam 客户端是否随包见 §5 法务）。
本轮目标：产出镜像 + 线刷包骨架；**rootfs 卡刷实机验证会清空用户数据，需另行确认后再做**。

## 1. 前置条件

- 平板在线（SSH root: `root@<ip>:2222`，密钥 `~/.ssh/j716f_key`）。
- SD 卡挂载在 `/mnt/sdcard`，≥ 40 GB 空闲（镜像 20G + gz 约 6–8G + simg 约 10–12G）。
- 设备已装：`android-tools`（`img2simg`）、`e2fsprogs`、`rsync`、`gzip`。
- 资产已推到设备 `/home/j716f/release-assets/`：
  - `build-rootfs.sh`、`sanitize.sh`、`j716f-firstboot.sh`
  - `rename-user-in-image.sh`、`j716f-user-setup.sh`、`j716f-user-setup-profile.sh`
  - `j716f-firstboot.service`、`j716f-boot-ok.service`、`j716f-mark-success.service`

## 2. 构建流程

### 2.1 先看清理目标（只读）

```bash
sudo /home/j716f/release-assets/build-rootfs.sh --inspect
```

看 `du -x -d1 /`、`/home/j716f`、`/opt`、SD 空间，确认：
- `/home/j716f` 里哪些必须保留（一般全清）；
- `/opt/steam-arm`、`/opt/fex-rootfs` 体积（决定是否 `--strip-steam`）；
- `j716f-mark-success.service` 是否 enabled。

### 2.2 构建（约 15–30 分钟）

```bash
# 默认 20G 镜像，产物 /mnt/sdcard/j716f-release
sudo /home/j716f/release-assets/build-rootfs.sh

# 公开版（更合规、更小）：剔除 Steam/FEX 二进制
sudo /home/j716f/release-assets/build-rootfs.sh --strip-steam

# 自定义
sudo /home/j716f/release-assets/build-rootfs.sh --size 24G --out /mnt/sdcard/j716f-release
```

脚本做的事：

1. 在 SD 卡上 `truncate` + `mkfs.ext4 -L J716F-ROOT`（20G 逻辑，首启 `resize2fs` 扩到 108G）；
2. `rsync -aHAX` 复制当前系统，排除：`/proc /sys /dev /run /tmp /mnt /media /home/j716f /root /var/log/journal /var/cache/pacman /var/lib/bluetooth /etc/NetworkManager/system-connections /etc/ssh/ssh_host_* /etc/machine-id /swapfile` 等；
3. **用户名通用化**（`rename-user-in-image.sh`）：`player` → 占位 `player`，家目录统一 `/home/j716f`，并替换 `/etc`、`/usr/local`、家目录里的引用；
4. 写入首启服务、boot-ok 服务、mark-success 服务、用户自定义 setup（profile + sudoers + pending 标记）；
5. 跑 `sanitize.sh`：清个人数据、重置 machine-id/SSH host key、占位用户默认密码 `player/j716f`、fstab 改 `LABEL=J716F-ROOT`；
6. `e2fsck` → 导出并裁剪 `boot.img`；
7. `gzip -1` 生成 `rootfs.img.gz`（卡刷）；
8. `img2simg` 生成 `rootfs.simg`（线刷）；
9. 生成 `SHA256SUMS`、`manifest.txt`。

### 2.3 检查产物

```bash
ls -lh /mnt/sdcard/j716f-release
cat /mnt/sdcard/j716f-release/manifest.txt
cat /mnt/sdcard/j716f-release/SHA256SUMS
```

建议再做一次"镜像内抽查"：

```bash
IMG=/mnt/sdcard/j716f-release/rootfs.img
mkdir -p /mnt/chk && sudo mount -o loop,ro "$IMG" /mnt/chk
ls /mnt/chk/home/j716f               # 应为空骨架
getent passwd 1000 | head -1         # 占位用户名 player、home=/home/j716f（在 chroot 里查）
ls /mnt/chk/etc/systemd/system/multi-user.target.wants/ | grep j716f
ls /mnt/chk/etc/j716f/ | grep -E 'user-setup-pending|steam-setup-mode'
grep -E 'LABEL=J716F-ROOT' /mnt/chk/etc/fstab
sudo grep -rIl -E 'CHANGEME|SERIALNUMBER|BEGIN OPENSSH PRIVATE KEY' /mnt/chk/etc /mnt/chk/home | head
sudo umount /mnt/chk
```

## 3. 卡刷包（SD 卡）

把 payload 放到 SD 卡（**不要**放在会被整盘覆盖的 userdata 上）：

```
<SD>/j716f/SHA256SUMS
<SD>/j716f/boot.img
<SD>/j716f/rootfs.img.gz     # 会整盘覆盖 userdata
```

直接用设备脚本生成 payload + TWRP zip：

```bash
sudo python3 /home/j716f/tools/make-cardflash.py \
  --boot /mnt/sdcard/j716f-release/boot.img \
  --rootfs /mnt/sdcard/j716f-release/rootfs.img.gz \
  --out /mnt/sdcard \
  --version v1.0.0 \
  --zip /mnt/sdcard/j716f-update.zip \
  --update-binary /home/j716f/tools/cardflash/update-binary \
  --qbootctl /root/qbootctl-src/build-static/qbootctl
```

- mini-recovery 只读裸文件布局（`/j716f/`），zip 是给 TWRP 生态的；
- 卡刷会清空 userdata（发布版本来就是清空重装）。

## 4. 线刷包（Windows）

目录结构（发布包根目录）：

```
j716f-arch-steam-v1.0.0/
├─ README.md
├─ SHA256SUMS
├─ manifest.txt
├─ install.ps1
├─ tools/platform-tools/fastboot.exe + 两个 DLL
├─ images/boot.img
└─ images/rootfs.simg
```

把 PC 上的 `release/lineflash/install.ps1` 放进包（`make-package.ps1` 会自动做），按脚本头部注释准备文件即可。
脚本行为：校验哈希 → 查 `product=TB-J716F`、`unlocked=yes`、`partition-size:userdata` → 二次确认 →
`fastboot flash boot_a/b` → `fastboot flash userdata rootfs.simg` → `set_active a` → `reboot`，全程写 `install-log.txt`。

> `fastboot flash userdata` 在本机仍未实测（需要 USB 连接 + PC）。
> 如果 ABL 拒绝，改走卡刷路线（mini-recovery + SD）。

## 5. 法务与分发

- 镜像内**不含** Steam 账号、登录态、游戏库、个人 WiFi/SSH/蓝牙数据；
- 发布版默认 `--strip-steam`：剔除 `/opt/steam-arm`、`/opt/fex-rootfs`，**不含 Valve 客户端**；
  首启进入 setup console（tty1 自动登录占位用户 `player`，用户先自定义用户名/密码，重启后配网），配网后运行 `sudo j716f-install-steam.sh`，
  由**用户设备自己**从 Valve CDN / Steam-ARM 社区安装器下载，脚本随包分发但不含 Valve 文件；
- 安装成功后的收尾：写 `/opt/steam-arm/.installed`、退出 setup console、恢复 greetd、重启进 Game Mode；
- `/usr/local/share/j716f/steam-arm-install.sh` 可选（若资产里放了社区安装器脚本就随包；它本身只是下载器）；
- 高通固件（`/lib/firmware/qcom/*`）为专有文件，随包分发有灰区（详见 docs/82 §8）；
- 内核 GPLv2：附源码地址（`kernel-src.tar.gz` 或 GitHub + .config + patch）；
- 不要包含原厂联想固件/他人数据；不收费刷机。
