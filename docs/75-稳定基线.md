# J716F 稳定基线（2026-11-08）

## 当前固定状态
- 内核：Arch ARM64 6.13 系列（具体版本见基线 `meta/packages.txt`）；
- 显示：**FSR 关闭，原生 2560×1600，60 帧上限**，去掉 `--force-composition`；
- Game Mode：Steam UI 使用 `-cef-force-gpu -cef-disable-gpu-sandbox`；
- MangoApp：仍启用（注意：全屏游戏内叠加可能被盖住，Steam 自带叠加用 Guide 键）；
- GPU：游戏时自动 `userspace + 670MHz`，退出自动 `simple_ondemand`；
- zram：8G lzo-rle；
- Steam UI 空闲页：`j716f-pageout-steamui.timer` 每 60 秒在游戏运行时换出到 zram；
- 蓝牙：**BlueZ 5.72** active，5.87 disabled；Steam UI 扫描/手柄可用；
- 充电：PD 9V/3A，满电 Full/Not charging；
- 快速启动看门狗：PC 侧 Windows 启动项 `fastboot-watchdog-v2`。

## 基线位置

## 恢复方法
```bash
sudo /home/j716f/j716f-baseline-current/restore.sh
```
- Steam 运行时不会覆盖 Steam config；
- 恢复 gamemode.conf 后需重启 Game Mode；
- 恢复前会自动把当前 `/etc/j716f` 和 gamemode 脚本备份到 `/root/`。

## 改动纪律
1. 任何改动前先记录/备份；优先使用基线恢复；
2. FSR/显示模式不要频繁切换；如果出现半屏，**先完整重启设备**，不要继续改参数；
3. 内核、BlueZ、gamescope、MangoHud 不做无备份升级；
4. `pacman -Syu` 前先做新的基线快照；
5. 只有验证稳定的改动才更新基线。

## 已知仍未解决
- Halo MCC / HFF 等 ARM64 兼容性；
- CPU 3.2GHz（设备树 OPP 只到 2.8416GHz）；
- GPU 905MHz（需内核/OPP 超频）；
- USB-C host/device 未测；
- 摄像头/麦克风不在此范围。
