# 36 · 快充驱动接入（PM8150B SMB5）— 2026-10-28

## 一、本次做了什么

目标：让 Linux 真正接管 PM8150B 内置的 SMB5 充电器，替换“引导程序 + PMIC 默认值”的 0.8A 慢充。

### 1. 驱动

| 文件 | 改动 |
|---|---|
| `drivers/power/supply/qcom_pm8150b_charger.c` | 新增（来自 armbian sm8250 补丁 0028，已叠加 0037/0039/0041） |
| `drivers/power/supply/Kconfig` | 新增 `CONFIG_CHARGER_QCOM_SMB5` |
| `drivers/power/supply/Makefile` | 新增 `obj-$(CONFIG_CHARGER_QCOM_SMB5) += qcom_pm8150b_charger.o` |
| `include/linux/power_supply.h` | 新增 `POWER_SUPPLY_PROP_CHARGING_ENABLED` 属性 |
| `drivers/power/supply/power_supply_sysfs.c` | 导出 `charging_enabled` sysfs |

驱动能力：
- 读取 APSD 结果，识别 SDP / CDP / DCP 充电器
- 自动设置输入限流（SDP 0.5A / CDP 3A / DCP 3.3A）
- 开启 AICL 自动输入电流爬升
- 按电池参数设置浮充电压（FV）
- 提供 `charging_enabled`、`current_max` 可写属性

### 2. 设备树

| 文件 | 改动 |
|---|---|
| `arch/arm64/boot/dts/qcom/pm8150b.dtsi` | 新增 `pm8150b_charger: charger@1000` 节点、ADC 通道 7/8（`usb_in_i_uv`、`usb_in_v_div_16`），来自补丁 0029 |
| `arch/arm64/boot/dts/qcom/sm8250-lenovo-j716f.dts` | include `pm8150b.dtsi`；新增 `battery` 节点（8600mAh / 3.4–4.45V）；启用 `&pm8150b_charger` 并绑定 `monitored-battery` |

### 3. 内核配置

```
CONFIG_CHARGER_QCOM_SMB5=y
```

已同时写入 `arch/arm64/configs/sm8250.config` 和当前 `.config`。

## 三、重启后验证

```bash
# 1. 驱动是否加载
dmesg | grep -iE 'smb5|pm8150b|charg'
ls /sys/class/power_supply/

# 2. 充电状态
for p in /sys/class/power_supply/*/; do
  echo "== $p"
  grep -E 'POWER_SUPPLY_(NAME|STATUS|ONLINE|USB_TYPE|CURRENT_MAX|CURRENT_NOW|VOLTAGE_NOW|CHARGING_ENABLED)' $p/uevent
done

# 3. 实际电流（对比原来的 801000uA）
cat /sys/class/power_supply/bq27541-0/current_now
```

预期：
- 出现 `pm8150b-charger`（或 `pm8150b_charger`）设备
- 插 5V 充电器时 `ONLINE=1`，`USB_TYPE` 为 `DCP`/`SDP`
- 输入限流自动升到充电器能力，`current_now` 明显高于 0.8A
- 若仍只有 0.8A 左右，说明电池侧 `FAST_CHARGE_CURRENT_CFG` 默认值偏低，下一步在驱动里显式设置快充电流

## 四、安全与回滚

- 首次测试请用 **5V 普通充电器**，不要直接上 9V/PD
- FV 设为 4.4475V（寄存器 0x81），不超过文档要求的 4.45V
- 温度 >45℃ 应降流；后续可接入 `qcom_fg` 和热区
- 若无法开机：EDL 刷回 `/home/j716f/backup/boot-before-charger.img` 或 `boot-safe.img`

## 五、下一步

1. 重启验证基础充电与电流提升
2. 若电流仍低：设置 `FAST_CHARGE_CURRENT_CFG`（0x61）到 3A 档，并按温度分档
3. 快充 PD 9V：启用 `&pm8150b_typec` + `usb-c-connector`，接主线的 `CONFIG_TYPEC_QCOM_PMIC`（当前内核已内置）
4. 接入 PM8150B FG（`qcom_fg`），替换/补充 bq27541 电量计
