## 二、修复的 4 个问题

### 1. `HEALTH=Cold` 导致降流
- **原因**：主板未接电池热敏电阻，硬件 JEITA 被禁用后 `BAT_TEMP_STATUS` 的 COLD 位悬空误触发
- **修复**：`qcom_pm8150b_charger.c` 的健康判断忽略 COLD 状态位，只信任过温位

### 2. SPMI 写报错刷屏（1820 条/启动）
- **原因**：`&pm8150_rtc { allow-set-time; }` 让 AP 去写 RTC 控制寄存器 `0x6046`
  （SID=0 的 RTC 写 APID 属于 RPM 固件，AP 无权写）
- **修复**：移除 `allow-set-time`

### 3. PM8150B FG 驱动写 SRAM 被拒、无校准档案
- **原因**：FG SRAM 的 SPMI APID 属于 ADSP 固件，AP 写入返回 `-EPERM` 并刷屏
- **修复**：DTS 中 `&pm8150b_fg` 设为 `status = "disabled"`，电池信息用
  `simple-battery` 节点 + BQ27541 电量计（内核日志已干净）

### 4. PD 源被误判成 SDP(500mA)、3A 被 APSD 覆盖
- **修复 A**：驱动读取 TCPM 的 PD 合约（`power-supplies = <&pm8150b_typec>`），
  5V/9V 档直接按 PD 合约设置 ICL
- **修复 B**：打开 AP ICL override 位（`CMD_ICL_OVERRIDE` / `USBIN_LOAD_CFG`），
  防止 APSD 检测完后把 ICL 改回 500mA

## 三、当前技术细节（便于后续继续调）
```
DTS 电池上限: constant-charge-current-max-microamp = <3000000>   ← 当前 3A 瓶颈
PD 请求档位: PDO_FIXED(5000,3000) + PDO_FIXED(9000,3000)        ← 用户已加 9V 档
实测: 电池 3A × 4.09V ≈ 12.3W；输入侧约 1.5A@8.38V
```
若以后想更快，只改 `constant-charge-current-max-microamp`（4.5A≈18W、5.5A≈22W），
并**必须**加软件温度守护（硬件 JEITA 禁用）：读 `/sys/class/power_supply/bq27541-0/temp`，
>400（40°C）降流、>450 停充。

## 四、键盘问题结论（原装 Pogo 键盘）
- 内核识别正常（`hid-over-i2c 17EF:610B`），但 **MCU 偶尔在开机后卡住**（i2c 能读描述符但不发按键中断）
- **解决办法（已验证）**：**完整关机 → 等 10 秒 → 按电源键开机**，键盘即恢复
  （仅拆装键盘不一定有效；整机断电才能复位 MCU）
- 根因推测：pogo 键盘的电源/检测逻辑（原厂由 SMB5 的 pogo_en/pogo_det 驱动负责）
  在 mainline 下没有实现，偶发 MCU 卡死；后续如果要做彻底修复，需要从原厂内核反推
  pogo 电源管理，工作量较大
