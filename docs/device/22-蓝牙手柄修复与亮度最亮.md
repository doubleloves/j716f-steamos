## 二、蓝牙手柄：配对显示成功但无法操作的根因与修复

### 现象
- `bluetoothctl devices` 里能看到 `Xbox Wireless Controller (AA:BB:CC:DD:EE:FF)`
- 但 `bluetoothctl devices Paired` / `Connected` **都是空的** → 实际配对从未完成
- bluez 日志刷屏：
  ```
  src/device.c:new_auth() No agent available for request type 2
  device_confirm_passkey: Operation not permitted
  ```
  → **系统中没有注册 BlueZ 配对代理（agent）**，配对确认请求无人应答，配对失败。
- 我们的会话是「直接启动 Steam Big Picture」，没有经过 XFCE 会话，所以 `blueman-applet` 从未启动
  → 没有 agent → 手柄"看起来配对过"但不可用。

### 修复步骤
1. **启动 BlueZ agent**：在 j716f 会话中启动 `blueman-applet`（它向 BlueZ 注册 org.bluez.Agent1），
   并加入 `.xinitrc` 开机自启：
   ```
   nohup blueman-applet >/tmp/blueman.log 2>&1 &
   ```
2. **删除坏的配对记录**：`bluetoothctl remove AA:BB:CC:DD:EE:FF`
3. **重新配对**（自动监听脚本 `bt-pair-watcher.sh`）：
   扫描 → 发现 Xbox Wireless Controller → `pair` → `trust` → `connect`
   - 结果：`Pairing successful`，日志显示 GATT 服务发现完成
4. **修复输入设备权限**：
   - 手柄经 BLE HID over GATT（BlueZ `hog` → 内核 `uhid` → `hid-microsoft`）注册为输入设备：
     ```
     /proc/bus/input/devices:
       Bus=0005 Vendor=045e Product=0b13
       Name="Xbox Wireless Controller"
       Handlers=kbd js0 event10
     dmesg:
       input: Xbox Wireless Controller → input11
       microsoft 0005:045E:0B13.0003: input,hidraw2: BLUETOOTH HID v0.23 Gamepad
       input: Microsoft X-Box 360 pad 0 → input12
     /dev/input/: js0, js1, event10
     ```
   - 补充 udev 规则 `/etc/udev/rules.d/61-xbox-hidraw.rules`（蓝牙手柄是 uhid 虚拟设备，没有 USB idVendor 属性，
     必须用 `KERNELS=="*045E:*"` 匹配）：
     ```
     KERNEL=="hidraw*", KERNELS=="*045E:0B13*", MODE="0660", GROUP="input", TAG+="uaccess"
     KERNEL=="hidraw*", KERNELS=="*045E:*", MODE="0660", GROUP="input", TAG+="uaccess"
     KERNEL=="js*", KERNELS=="*045E:*", MODE="0664", GROUP="input", TAG+="uaccess"
     ```
   - 修复后：`/dev/hidraw2` 权限 `crw-rw---- root input`，j716f 可读 ✓
5. Steam 端：进程已打开 `/dev/input/event10`，controller.txt 日志显示控制器配置已加载
   （`Queueing activation for controller: 0`），**用户实测：按手柄 Steam 大屏幕界面有反应 = 可用** ✅

## 三、持久化 / 注意事项

1. **配对持久化**：`trusted: yes` + bluez `AutoEnable=true` → 手柄开机自动重连（只要手柄电源开、在范围内）。
2. **agent 自启动**：`.xinitrc` 已加 `blueman-applet`（没有它，下次重新配对新设备还会失败）。
3. **udev 规则**：`/etc/udev/rules.d/61-xbox-hidraw.rules`、`60-steam-arm-gamepad-hidraw.rules`、`60-steam-input.rules` 持久化。
4. **重刷镜像时**要带上：blueman 自启动、61-xbox-hidraw.rules、以及 bluetoothd 的 AutoEnable 配置。
5. 已知小问题（无害）：
   - dmesg `Bluetooth: hci0: Bad flag given (0x1) vs supported (0x0)` —— QCA6390 不支持 wake flag，忽略。
   - `deviceinfo: Error reading PNP_ID value` —— Xbox 控制器不提供 PNP_ID，忽略。
6. **其他手柄**（PS4/PS5/Switch Pro/8BitDo）：如果厂商 ID 不是 045e，需要把对应规则加进 `61-xbox-hidraw.rules` 或沿用 Steam-ARM 自带的 `60-steam-arm-gamepad-hidraw.rules`。
