## 三、槽位计数 ✅ 实用方案（PC 看门狗自动恢复）

### 结论：计数器在 RPMB，Linux 无法修改
通过「快照 → 重启 → 对比」验证：
- 对 **misc / devinfo / frp / secdata / storsec / uefivarstore / keystore / metadata / persist / logfs / lenovocust / lenovoraw / vm-* / ssd / fpinfo** 等 20+ 分区做重启前后对比
- **仅 logfs（ABL 日志）变化**，其余全部不变
- 向 misc@2048 写入合法 AOSP `bootloader_control`（标记 slot A successful=1）后重启：misc 未被 ABL 修改，且计数仍照常递减 → **确认存于 RPMB（TEE/QSEE 保护）**
- 因此：**无法从 Linux 侧重置计数**；只有 `fastboot set_active a`（ABL 内）能重置为 7

### 解决方案：PC 端 Fastboot 看门狗 🐕
- 脚本：`tablet/fastboot-watchdog-en.ps1` + `tablet/start-watchdog.vbs`
- 原理：PC 后台每 2 秒检测 fastboot 设备 → 一旦平板落入 fastboot，自动执行
  `fastboot set_active a`（计数重置 7）→ `fastboot reboot` → 平板自动回到 Steam
- 已安装：**Windows 启动文件夹快捷方式**（`%APPDATA%\...\Startup\Fastboot-Watchdog.lnk`），开机自动运行、无窗口
- 日志：`D:\xiaoxinpadpro\inspect\watchdog.log`
- **实测**：今日 18:43 平板进 fastboot（retry=0/unbootable）→ 手动执行同命令成功恢复（retry 7 → 正常启动）
- ⚠️ 前提：**平板 USB 连接电脑**（fastboot 走 USB；WiFi 不行）

### 使用注意
- 重启约 7 次后可能短暂进 fastboot（屏幕显示 FASTBOOT MODE），**电脑上运行着看门狗就会在几秒内自动救回**
- 若电脑关了/没插线：手动把平板连电脑 → 运行 `tablet/fastboot-watchdog-en.ps1`（或手动 `fastboot set_active a` + `fastboot reboot`）
